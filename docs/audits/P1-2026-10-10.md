## 时延与成本

原生与 Humanize 用户任务 SHA256 相同，base/env/model/effort 相同。原生 API 流耗时合计 8.681856 秒，Humanize 7.973419 秒；总时长减去 API 流分别为 4.475074、4.383654 秒。该残差包含启动、工具、SDK、隔离、验证和收尾，不能叫纯调度开销。Humanize 总时长减 driver.turn 为 0.887720 秒，是框架外围与验证/收尾的合计。观察到总差 -0.799857 秒，API 时长差占 -0.708437 秒；没有足够证据声称框架加速。原生 profile 与 Humanize composition、缓存及输出 Token 不完全相同，详见 ADR-0007。服务端排队/独立工具时间 unavailable；全部 30 个付费请求 HTTP 200，未观察到 API 限流或重试，不等于证明将来不会限流。每请求 first_delta/elapsed 和账本保留在本地。

P1 单独预算：30/40 DeepSeek 请求、3/6 Codex 订阅回合。API 保守峰值现金上界 USD **0.0770688**；按真实 cache hit/miss 和公开峰谷价估算 USD **0.009915264–0.019830528**，实际账单 **unavailable**。不能把上界或估算当账单。价格依据 [DeepSeek 定价](https://api-docs.deepseek.com/quick_start/pricing/)；原始请求上界按缓存也算峰值 miss，故更保守。

DeepSeek 非重叠计数：input/cache-read/output = **40,928 / 194,688 / 5,320**。Chat Completions 的 prompt_total=235,616；缓存 creation 没有独立计费/返回字段，映射明确记为 not_applicable，未把缺失 usage 随意补零。官方字段语义见 [Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)。Codex 从真实 rollout 提取 input/cached/output = **140,968 / 107,264 / 3,422**，cached 是 input 子集；reasoning=48 是 output 子集，total=144,390。订阅 API 现金 0，订阅美元成本 unavailable。Humanize 显示的 cost=0 和缺失 input 不作为免费或零 Token 的依据。P0 ledger 保持独立不重置，开发聊天本身的 Token/成本 unavailable，未纳入实验账本冒充可测数据。

## 失败、控制与边界

三个最初失败都在付费代理执行前，真实 API 请求 0、Codex 回合 0：错误 CLI 参数 `--dsh-home`；回环 proxy bypass；适配 subclass 未保留 backend 元数据。原始第二个记录保留历史 FAIL，但根因为 transport 基础设施失败，不是模型错误。修复和无付费 mock 端点诊断均保留；mock 结果没有计入模型可用性。

12 项离线控制 PASS：拒绝无授权客户端、替代路由、其他模型；策略拒绝不预占；发送前先预占；下一请求超额拒绝；过期拒绝；合成凭据、控制进程 environ/mem/fd 均拒绝读取。真实 Linux ledger 并发、未知 usage、重启/损坏、计数与订阅上限由预算回归测试覆盖；CI 不发模型请求。实现入口为 `scripts/run_p1_experiment.py`，不要直接运行无预算 gate 的 Flow 代替它。

P1 的孤立合成任务只验证基础协作和资源记录，不证明 DS-Enhanced、LAV/Jev、候选融合或科研质量有效。P2 的候选池并发与各自会话状态根、P3 的 M、P4 的工程记忆和产品 PR 人审均仍按原需求等待实施。没有充值、改仓库权限、启用严格 main 保护或启动 P2。

回滚开发实现用新分支 `git revert` 相关 P1 提交并经 PR/CI，同步 main；不用 reset/强推、删除失败 refs/VHD 或重置账本。合成实验可从项目本地八个 bundle clone 到新的 D 盘项目目录复验，保留原失败仓库。
