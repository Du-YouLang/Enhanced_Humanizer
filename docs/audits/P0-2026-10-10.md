## 发现的技术阻碍

1. **自主 agent 的隔离尚未成立。** [Humanize 安全说明](https://docs.humanfia.ai/humanize/user/security)使用 Landlock / Seatbelt；Windows wheel/初始化成功不等于真实执行有 OS fence。DSH driver 仅 bypass rung，必须外部隔离。未通过拒绝测试前不启动有工具写权限的 Flow；需要系统变更时另请用户授权。
2. **真实模型行为与计量未验收。** `/models` 与 Codex 登录/缓存不能证明工具、恢复、实际 gpt-6.1-sol 权限、usage 或性能；本轮没有生成请求。Humanize 对 Codex 的 driver 文档参照 0.153.4，与本机 alpha 不同，需真实协议 smoke。
3. **LAV/Jev 有独立条件。** LAV 必须实测 score-token logprobs；不能把 Sol 结构化评价当原版概率评分。项目环境未发现 Jev/TypeSafe key，未搜索密码库；Jev 为 BLOCKED_CREDENTIAL，示例库 license 未检测到，不复制源码。
4. **GitHub 写权限/套餐未验收。** 身份/API读取成功；同名仓库查询404。期间 gh 出现本机连接中止，公开 metadata 用 Python HTTPS 读成功，属于间歇性网络/客户端问题，推送时需重试和区分 INFRA_FAIL。既有 credential helper 指向 Anaconda；私有 push 必须实际验证。私有 main 保护是否支持不能提前承诺。
5. **费用硬限需要外部预留。** fake 预算最初单轮探针未抛超限，检查 SDK 后证实下一轮前才拒绝；已修正为两轮探针并保留负记录。正式请求需提前限制输入/输出/次数/超时，不能只靠事后累计。
6. **运行时默认缓存曾越界，已纠正。** 首次 DSH initialize 将两个新 native cache 写入用户 `.cache/pkg`；按创建时间与精确路径核实后已移回项目，固定 PKG_NATIVE_CACHE_PATH 并复测，旧目录已不存在。记录 `native-cache-correction.json`。
7. **科研材料尚缺，但不阻塞 P0–P5。** 四项科学任务的论文/数据/真值到 P6 前提供；GPU 已可识别，但固定科学环境与数值正确性未验证。
