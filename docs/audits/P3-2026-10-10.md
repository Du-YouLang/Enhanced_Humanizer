混合实验两个运行段为62.092和135.154秒；人工等待不计入1200秒活动上限，UTC 边界和真实 segment 均记录。全失败和矛盾池的初筛是确定性 J0，合成后的比较是独立真实 Sol/J3；算法身份无替换。合成成功仅代表这些固定小任务的机制可用，不证明真实科研成功率提高。混合池本来已有 A 通过，因此 M 没增加该池成功任务数。

DS 回接的 B 完成5次请求后，被全阶段并发现金预留门禁拒绝下一次请求（原始原因 P3 request/cash cap exhausted），不是触及12次单候选请求数上限。三个请求并发时按模型最大输入/输出预留最坏现金，累计已用金额加待决预留会暂时超过 USD 1；结算后实际保守费用仅 USD 0.065025。B 的未提交工作区代码通过独立测试，但尚未产生模型的新提交，完整执行没有成功结束，最终仍为 BUDGET_EXHAUSTED。A/C 各8次请求，完整通过。保留 B 的原始 HEAD、dirty 工作区、测试与工具日志；另由程序将完整未提交文件归档到新快照分支和 bundle，明确标记 PROGRAM_PARTIAL_SNAPSHOT_NOT_MODEL_SUCCESS，不冒充模型提交或成功。不重跑刷成功。失败 worker 的最终 session_id 为 unavailable，独立 HOME/工作区/运行隔离证据仍保留，不把它算作完整成功会话。

9个真实 Sol 角色分别使用独立 session，实际 model_id 全为 gpt-6.1-sol。所有角色为 uid1000、CapEff0、独立 PID namespace；Reviewer/Builder 可写自己 worktree，Verifier 不可写。实际运行 fence 拒绝控制器契约、隐藏验收模块、冻结基线 Git 配置、原候选源码和前角色 canary 的读写；只读 handoff 与认证文件拒绝写入。原候选和 main 不可写。必要官方 API 主机通过 Harness 代理，任务禁止任意联网或安装依赖。

程序 handoff 不传前角色对话、隐藏测试程序或答案；保留失败代码和公开测试，不只传获胜者。新的 DS 批处理任务显式改变任务契约，基于 Sol Builder 新提交；不拿它与原任务冒充同任务性能对照。完整会话和账本保存在项目私有 WSL 状态中；公开内容仅限本阶段已审阅的合成输入/代码/摘要。
