## 必须在结论中保留的边界

1. DS wire1000/600/五次恢复可精确控制。Codex CLI内层请求数目前不可完整计量，外层只有独立订阅回合；CLI stream idle timeout不等于600秒总请求期限。统一底层策略仍待单独验证，不声称已全部满足。
2. 完整缓冲可以安全重连，但延迟Harness收到第一段；provider首delta和最终完整交付须分开解释。HTTP429重连仍可能耗费队列时间；服务端硬输出/上下文上限无法由客户端保证突破。
3. 请求600秒不意味着每角色可完成五个600秒失败尝试。900/1200秒耗尽时保存网络待重试；不会擅自扩大原角色/整题时间。
4. USD25.0755186是修订时主集累积保守上界，不是账单。失败请求未知usage仍计峰价预留，10000次/USD100不会重置。Pi订阅访问只加一个订阅回合，价目估计不转为现金费用。
5. 单次重复、单题5/6及零模型fixture不支持“增强/融合/某Harness更强”的因果结论。旧基础设施缺陷、任务难度、顺序/GPU竞争、Skill提示额外Token需要分开分析；首次有效patch/首次通过测试时间和人类工作计时仍有测量缺口。
6. 本机HTTP请求正文大小有限，但尚未对慢请求连接/活跃线程做全面资源压力验收；本地威胁与长期服务稳健性仍需产品后续验证。

Pi官方订阅OAuth访问已真实通过gpt-6.1-sol（21输入/5输出Token、4.443秒、无工具）。账号字段在新token中加密，无法明文比较，按人类亲自选择记录；不要求再发送凭据。Pi四组比较仍须工具/计量/公开和私有gate后才能开跑。
