# ADR-0057: Fresh three-model comparison on the original sixteen tasks

Status: authorized scope; execution requires exact native controls and CI receipts.
Date: 2026-11-26.

The human requested GPT-6.1-Sol, GPT-6.2-Sol and DeepSeek V4.1 Flash-1017 on all sixteen frozen tasks, both directly and through the original full enhancement, plus a single-agent resource control. They approved cumulative 25000 DeepSeek requests and the unchanged cumulative USD500 ceiling. Previous requests, subscription reservations, unknown usage, programs and outcomes remain immutable.

There are 144 final result cells (16 tasks × 3 tested models × 3 methods):

- Direct: one native Humanize/DSH or Humanize/Codex session using the tested model.
- Enhanced: three independent tested-model builders run concurrently; fixed GPT-6.1-Sol independently judges the pool, implements or refuses synthesis, then independently judges the expanded pool. Public and GPU evaluation stay serial. This is a hybrid flow; Enhanced-GPT62 does not mean every role runs GPT62.
- SingleAgent-MatchedBudget: six bounded turns in one official session using the tested model and its own accumulated context; no mentor, other candidate, or hidden acceptance feedback.

The matched axis is the ceiling on aggregate model activity: six public 900-second or scientific 1200-second role slots. Actual tokens, requests, subscription reservations, cash bounds, model active time and elapsed method time are reported separately. This does not equalize actual tokens, provider prices, number of independent contexts, or elapsed time under parallel builders. Fixed-model review is part of the product flow rather than a homogeneous-model comparison. Counterbalance method order and model order across tasks. All three selected programs freeze before hidden evaluation for a model-task group.

Reuse the existing official Harnesses and tools. Install the official Codex CLI in an isolated versioned directory, bind its hash and actual selected executable, and reject returned-model drift. DeepSeek uses its official deepseek-flash alias; record the currently documented Flash-1017 mapping rather than claiming an immutable endpoint version. Official CLI model enumeration is an access preflight, not completed inference. Keep the original low effort, 1000 requests per role, DeepSeek output cap256000, 600-second wire timeout and ten-attempt transport policy. A six-turn session has six separate exact billing scopes; its cumulative usage is counted once. OpenAI per-wire counts/cash remain unavailable where the native subscription trace does not expose them.

Controller handoffs contain full public input inline and at a read-only exact path, with byte count/hash and observable tool-result acknowledgment. No acknowledgment is an infrastructure handoff outcome, not proof that the model cannot solve the task. Existing test/dependency immutability, private-oracle fencing, product PR human review and release gates remain.

Before dispatch: full local tests; actual sixteen-task public gold/hidden gold/buggy controls; actual96 OS-fenced roles; official fake six-turn same-session tests for all three models in both time families; exact three GitHub CI checks; frozen source/hash binding; then same-lock ledger archive and scope-only amendment. Controls dispatch no providers and must leave the real ledger byte-identical.

Each run has exact boot/PID/startticks/command-hash ownership, 30-second observation and per-role journal checkpoints. No automatic paid boot restart or completed-role replay. An uncertain started role must be reconciled before continuation; preserve its logs/reservations. Native source snapshots are never edited in place.

Independent source, numerical method, report and saved-figure review is required for scientific success. Numeric PASS alone is insufficient. Historical PC/EGL clock gaps, STROKE input whitelist and GRANGER synchronization failures are not waived. New clock pairs, child CPU measurements and explicit unavailable GPU timings prevent invented telemetry. Local HDD/GPU contention and historical SSD differences limit cross-era speed comparisons. This one-seed sixteen-task pilot does not establish universal superiority or lower token usage.
