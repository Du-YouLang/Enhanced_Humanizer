# ADR-0014：公共 smoke 的真实失败、只读评分与显式恢复

2026-10-11，P6 已批准的两项 smoke 使用独立 Ledger。Black 首轮实际 DS 编码触及单候选20请求保护门禁，N3没有合格交付；原生 Sol 后续独立隐藏验收通过。Reviewer 的部分代码可通过隐藏测试，但超时/脏工作区仍不可入选，不能称为成功候选。所有停止、错误评分、脏代码、Git对象与成本记录保留，不重置账本，不据此宣称任何增强收益。

原生 Codex 只读工具先因缺少 bubblewrap 无法读取评分输入。项目内非 root 下载并校验 Ubuntu bubblewrap 0.9.0-1build1（deb SHA `dde30d1f24da50446d647ed504ec8dc5a714f171974d054c70a589b48ba38b48`），未修改 AppArmor/sysctl 或全局安装。但外层 Humanize Landlock 已隐藏系统路径，内层 Codex bubblewrap 无法枚举该文件系统。依据上游 Humanize 的双层权限设计，只对明确 `local=read,user/system/online=none` 且有实际 Fence transform 的 Codex Verifier，避免重复内层 sandbox；外层进程及所有子工具仍继承只读 Landlock、网络代理与私有 PID/mount/user namespace。Builder 权限不借此放宽。

评分前实际探针须证明：uid1000/CapEff0/私有PID、自身代码不可写、输入/封存环境/单一必要 Codex 认证文件不可写，参考答案/控制器/其他候选不可读。新原生 J3 已实际读取完整公共输入并覆盖所有候选，原错误空评分仍记录为不可用。没有用 Sol 冒充 Jev 或概率分数。官方 Codex Linux/WSL2 sandbox 前置说明见 [OpenAI 文档](https://learn.chatgpt.com/docs/sandboxing)；本例的外层完整进程隔离是固定 Humanize 的实际实现，不能推广为任意 `bypass` 安全。

浅克隆 Git bundle 缺失 shallow boundary，直接 clone 会报告缺少父对象。接力改为从同一冻结基线独立 clone（保留 shallow marker），再 fetch 在候选隔离边界内导出的 bundle。禁用 hooks/fsmonitor/global配置/凭据助手、无共享对象库，导出前检查路径链接；恢复已保存的脏补丁和有界新增文件。保留 diff 原始空白，避免 `.strip()` 丢失补丁末行；实际原生零模型测试覆盖浅历史、新提交、未提交修改、新增文件、无 alternates/remote。

显式 `--reuse-run` 校验原 task、manifest、prompt 与冻结池 hash，复用既有候选/独立角色，不重生成已付费 DS 或重复已完成 Sol。原账本累计，所有历史 worker 活动保守求和从1200秒扣除（并行求和也不视为免费）。修复/等待时长单独报告，不将源码实施者工作时间记为模型速度。每项后续模型运行保存实际部署源码快照与 hash；早期停止尝试保留原 source hash/日志，部分未提交控制器源码的逐字快照不可用，不能称完整可重现。

Black 的原 J1 保护门禁拒绝上游默认65536输出；没有发送该超额请求。设置与已验收 P2 相同的官方环境选项 `DEEPSEEK_EFFORT=off`、`DEEPSEEK_MAX_TOKENS=4096` 后，仅重新评分同一冻结池；原 PPT/logprob 算法与 score-token 概率提取未改写，字面分数后备继续拒绝。真实 probe/cost 与首次零请求配置错误分别记录。Jev 仍地区阻塞，零调用。

本轮是连通性/执行链 smoke，额外单候选 DS20请求/$1、Codex整turn115秒（保守满足请求≤120秒）会影响可交付率；DS 与 Sol 实际可用生成时间/调用数不等，恢复后的墙钟也不同于连续实验。主集须重新明确统一操作限额、原生请求可观察性、等时间/等现金比较和完整轨迹敏感性协议，再独立申请预算。不得把当前两项 smoke 的失败/通过率作模型能力或效能排名。完整 P6 Gate 仍待主集与用户暂缓的科研验收，GitHub 继续暂缓。
