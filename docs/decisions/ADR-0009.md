# ADR-0009：独立合成与 Sol→DS 回接

日期：2026-10-10。状态：已实施并通过真实功能与独立复验；Git 交付另看 P3 验收记录。

用户已授权 P3 和独立预算：DeepSeek USD 1 / 40 请求、现有 Codex 订阅12实验回合；每请求120秒、候选/角色600秒、实验累计活动时间1200秒，不充值。Jev 因用户报告的地区限制保持不可用；采用明确标识的 Sol/J3，不能称作 Jev 或校准概率。

复用 Humanize 原生 resumable Flow、官方 Codex/DSH Harness。控制器只负责冻结证据、预算、角色调度、隔离和独立验收，不实现新的 Coding Harness。Reviewer、Verifier、Builder 每次拥有新会话、独立 HOME/backend state/worktree、非 root 私有 PID/mount/user namespace；通过实际 Humanize fence 测试跨候选/控制器/其他会话的访问拒绝。认证在原有项目 Linux 登录位置读取，不复制全局认证目录；移除认证目录及认证文件的写授权，单文件只读。自己的 Harness 必须能读自己的登录凭据，不宣称凭据对其自身不可见。

程序 handoff 包含所有成功与失败候选完整文本文件、公开测试、硬验收摘要和固定任务/环境/提交哈希；不传前角色聊天、隐藏测试程序或答案。Reviewer 可重写或明确拒绝，在新 worktree 实际实现 M。A..N 与 M 用同一冻结测试和环境；M 仅新增候选，不自动获胜。Sol/J3 对 A..N+M 独立评分，硬验收失败不能被评分覆盖。

混合池使用独立 Sol/J3 初筛，再 Reviewer→硬测 M→独立 Sol/J3→独立 Sol Builder→新 DS N3→独立 Sol/J3。全失败/矛盾任务使用确定性 J0 初筛，再真实 Reviewer 和独立 Sol/J3 比较 M；初筛算法身份保留，不冒充 Sol。三个池使用 P2 合成受控故障和一个明确矛盾契约，覆盖机制，不证明科研或真实工程增益。DS 回接任务显式增加批处理功能，以 Sol 新提交为固定父版本，新的任务/隐藏测试明确记录。

在角色边界写不可变 checkpoint，然后原生 Run.stop；另一个 CLI 进程从同一 epic 恢复。已完成阶段读缓存和哈希，不能重复扣费。恢复前核验部署源码、任务/环境/证据哈希；更改执行源码须保留旧尝试并开新实验。实验1200秒为各运行段累计活动时间，人工等待单独记录；当前不承诺瞬时中断任意工具。失败和部分代码、日志、会话、Git refs/bundles 均保留，基础设施失败立即停止后续模型动作。

初次真实入口因认证文件精确写授权遗漏被实际 fence 拒绝，启动预留仍计入账本。修复后先运行零模型三角色权限回归，再运行新实验；不得重置额度或将控制实验冒充真实模型结果。公开归档仅限本阶段固定合成代码/审阅后的摘要，不包含密钥、完整对话、真实科研材料。

P3 只完成此执行闭环。通用 SQLite/NDJSON 记忆、任意节点恢复、探索 UI 和16任务科学消融仍属 P4–P6。产品生成的每次 PR 仍必须人工审核；本项目开发 PR 遵循 ADR-0004。
