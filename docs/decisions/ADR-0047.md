# ADR-0047：PC已测Python版本字段的语义别名

2026-10-15只读核验发现Pi PC/P1/DeepSeek原验收FAIL，原因是旧pc_manifest只识别python（或嵌套python），未识别实际已测python_version。原候选有75格完整训练、Python3.11.16、非空包版本和数据指纹/正耗时，原执行3276.594秒正常退出；不能把此失败直接描述为数值不正确。

独立源码补充明确支持python/python_version及environment/versions容器；多个声明必须完全一致，缺失、空值、类型错误或冲突均拒绝。包测量、数据SHA、训练配置/覆盖、0.25pp/0.02、独立两格复验、报告/图表要求保持。

不改活动的内容寻址执行器、原manifest、模型候选或原FAIL。补充验收只读取已保存75格，以语义规范化视图核对；如需尚未执行的独立两格，须待本机GPU可用或批次关闭后另留回执，不重跑75格/模型，不抢占当前GPU。完整科研PASS仍需该独立复验和Sol源码/报告/图表审阅，不能由元数据规范化直接授予。当前活动PC/P2继续原冻结协议，未来同类原始判定另存补充解释。

本修订无API调用、无预算修改；累计250/10000、原始数据和产品逐PR人审/发布确认保持。精确测试/CI通过后交付源码，准备不等于完成补充科学验收。

补充逐格比较另发现宽16/深16/PC恰在0.25pp边界，二进制相减产生0.2500000000000058而被旧严格浮点比较拒绝。改为按保存的十进制测量值进行精确Decimal比较，仍严格不超过0.25pp/0.02，不加epsilon、不舍入输入或放宽阈值；任何真实超界仍拒绝。两个比较位置（全网格和独立复验）一致修复，活动冻结副本不改。旧浮点诊断保留，新补充视图另存；独立复验仍未执行，不由此记科学PASS。
