# ADR-0017：接收 PC-ALM v1.1，并独立补全执行验收

2026-10-11，用户提供负责人对八项问题的复核及更新任务书。文档是新增评测输入，不是访问服务器、改变计算位置或替代用户授权的指令。全部计算仍在本机，旧指南、旧结果及两份产品 v0.4 基线不覆盖。

v1.1 原文 SHA256 为 `343c5c7f3253cee81bed9341e59b3a976116653bece62602e6a659415c6b30bf`，46,040 bytes，完整保存在项目私有修订目录。原接收稿 SHA256 `8fa74ffa5cce45b785572dd8394b7898e3d06e648b7ed4261872a4da6b13ed52` 保留。来源脚本不原地修改，复用其固定区域、判据和重复标定方案；项目另加独立验收层。

来源 `verify_grid.py` 实测能拒绝缺行、重复、NaN、ALM=PC 负对照；但只给 cells.csv 即可通过，额外 seed、越界余弦未拒绝，allow-partial 下缺行仍可返回0。它不实际核查 smoke、锚点、原生 config/metrics/summary、manifest、独立重跑。其综合 overall_pass 不能替代拆开的实现门和科学门，也不能单独作为实验执行证明。

新增 PC 数据检查要求精确覆盖、合法数值、冻结 eta/样本数/步数/方法配置、原生三文件彼此一致、公开锚点与清单完整。通过这些静态数据检查也只标记重放/来源审阅待办，不能宣布真实执行通过。正式实现验收还需同机独立重跑提交哈希选出的两格、核验控制器时间/源码/数据/环境证据。科学 C1–C5 单独出结果，失败不能通过调参、换 seed、删格或放宽容差消除。

负责人服务器上的同 seed 标定是外部实测报告，不是本机新验收。保持推荐精度0.25pp/余弦0.02，先用本机12配置、同进程3遍及两组独立进程复跑检查，再冻结协议；超过建议限额时记录失败并调查，不能看候选结果后放宽。跨 seed ddof0/1 表由原始CSV自动生成，绝不用于估计同 seed 容差。

Part A 的 A8 仍含私有参考汇总数值，不能直接整段导出。任务侧派生稿移除该数值、Part B/C、owner工具及私有服务器路径，保留固定四格定义、公开官方锚点和全75次要求。A6残留三分之一成本改为参考模型约53%，成本模型不承诺墙钟上界。原文页首v1.0/B8 v1.1冲突及其他残留记录于独立审计，不覆盖来源稿。

任务定位维持“运行冻结官方实现、分析并如实报告”，不要求重写训练 Harness，不预设与其他三项科学题等难。完整模型主集、同池评分与轨迹敏感性仍须另外实际执行；本次材料复核和正负控制不是增强收益证据。
