# ADR-0038 — 科研全失败的契约归因与只读复核

日期：2026-10-14。状态：归因核验完成，STROKE契约待裁决；原成绩不改。

用户要求查验原四项科研任务中三项六臂全失败的原因。保留原结果，不整题重跑、不改冻结协议，累计USD200/10000请求上限不变，GitHub暂缓。复核只读取源码、回执和原生保留产物；候选Git检查在既有无网络隔离中执行，不运行候选或模型。

EGL/PC的验收器和契约问题已经由ADR-0037另存修复与补充判定。新发现是STROKE七份已执行原候选的98份输出，21类数组全部符合原冻结规则；失败只涉及四份候选的等价ROI键，以及七份候选在无峰/全零情况下两个NF辅助标量的约定。公开契约没有充分定义这些键/条件。原比较器依原规则报告FAIL的事实成立，但“全部核心数值计算错误”的推论不成立。

原FAIL、原P6报告和所有回执保持不可变。新增归因标签CONTRACT_ADJUDICATION_PENDING仅作解释，不替换判分、不计入通过率。重复性/输入拒绝/实质源码与图表审阅尚缺，不把离线数组一致冒充整题PASS。Reviewer M因结构化交接门未获数值执行，单列未执行，不造数值成绩。

以后独立版本需冻结完整metadata schema及无显著增强/全零输入的标量类型与数值语义，并通过真实隔离CLI正负控制，才能建立新的可比矩阵；本次不启动该矩阵。之前P6报告的STROKE“明确协议/数值失败”概括由独立补充纠正，不回写旧证据。详情见[归因审计](../audits/Scientific-all-fail-attribution-2026-10-14.md)。

三个全失败任务的模型角色均在1200秒内正常结束，不能归因为统一超时。六臂使用共享池/继承路径和同一个验收器，也不能当六种独立模型的六次失败。真实PC F偏差、EGL B/M/F偏差、历史缺失计量及Pi原同步缺陷仍保留，不能因发现共同接口问题而一并豁免。
