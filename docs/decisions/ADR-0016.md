# ADR-0016：本机完整评测授权、独立主集账本和科学任务修订

2026-10-11，用户明确授权复制必要外部代码到项目、针对性修正 benchmark、开始实验及 GitHub 提交；API 不设累计金额上限。随后确认“全部在本机，保留冻结的 CPU 协议”。这取代公共主集“等我自行决定”、科学材料暂缓和 GitHub 暂缓；外部产品发布仍需另行确认，每个产品 PR 的人工审核要求不变。

采用独立 P6_MAIN_LOCAL_20261011 账本与 configs/budget-p6-main-approved.json，不修改/结转旧 smoke 和 P0–P5 账本。累计 API金额/请求数/订阅回合以 null 表示用户未设上限，不能以任意大数字冒充已批准金额；仍逐请求预记未知用量、据可见Token结算保守上界，账单和订阅成本不可见时为 unavailable。为防失控循环，保留请求120秒、统一编码整turn115秒、每角色20请求/1订阅回合、活动实验1200秒；基础设施故障不自动无限重试，不充值。

原16项方向、12公共身份/base/material SHA、seed42、N3、A–F与原版J0/J1/独立J3保持。旧v1/v2清单与结果不重写；新任务环境、源码、权限和可见/私有材料组成新版本。在任务负基线确实失败、可信参考通过、实际隔离拒绝和资源限制通过后才发题。任务准备失败如实报INFRA_FAIL/缺料，不能换题或当模型失败。

科学材料及任何衍生参考实现默认放项目私有 .local-workbench/scientific-intake 和同一D盘WSL VHD。公开仓库只提交通用适配代码、来源指纹与脱敏审计，不上传论文、研究输入、私有oracle、旧答案或原始模型轨迹。复用官方科学源码不构建新 Coding Harness；仍使用 Humanize + DSH/Codex。

科学首版候选范围为 PC-ALM Fashion/ReLU 单seed的完整25格×3方法（保留smoke和锚点）、TMS指定两论文的传感器级算法重建及小样本数值图表、EGL原Figure4B r-of-k CPU主任务、GC冻结ridge方程的CuPy实现。TMS不声称患者诊断/临床指标复现；EGL可选DSAINet EEG扩展留为后续范围，不让A800成为主任务前置条件。科学声称是否复现与实现是否忠实分开记录。

PC-ALM修正文字/验收脚本不一致的判据、固定深窄四格、非零失败退出及统计ddof；GC/EGL候选导入执行与持有gold的裁判分进程且通过OS隔离；TMS在Linux补进程树资源控制。先在固定本机环境做正负对照和跨平台校准，再冻结容差，不能看到候选后改阈值或删格子。

模型活动和长科学计算分别记账、分别限时：独立科学验收PC7200秒、TMS600秒、EGL1800秒、GC180秒，每个完整验收严格串行；这些是防失控上限，不是耗时承诺。编码阶段只运行冻结的小规模公开检查，完整科学验收由可信控制器执行；若Verifier/Reviewer需要运行反馈，其可见反馈和活动计时也须先统一冻结。不能把耗时藏在免费预处理或以不同硬件比较A–F。正式公平主集须同时报告墙钟、活动、独立验收时间和模型/工具明细。

所有计算仅用本机CPU/4060；不使用4090/A800计算，不停止他人进程，不租云卡。环境/缓存/日志/中间材料仍留D盘项目，保留微软系统组件C盘既有例外。当前本机GPU/CPU协议经用户明确确认；即使JAX/依赖失败，也不能默默改精度、数据、seed、epoch或网格。

GitHub在重新核验Du-YouLang身份/同名公开仓库权限后恢复开发交付。按P4→P5→P6→P7补交PR并实际检查对应head的CI；不增加严格main保护、协作者或改变可见性。产品发布审批凭据只来自真实所有者浏览器操作，绑定精确提交/目标/测试证据并一次性使用，不能继承开发授权。

本ADR记录授权与协议决策，不声明任务环境、完整主集或产品PR已验收；完成情况进入后续独立审计和traceability。

本机 EGL 可信参考初验发现原指导书 18 项末点中 17 项与公开冻结算法的本机结果一致，N20000/GD/seed3 相差5.4pp，超过原跨机容差。保留旧表、全部本机轨迹及失败对照；先核验同机重复和数据/权重重放，再决定本机新版参考是否可冻结。不得删该seed、放宽候选容差或把不一致称为原远程基线通过。其余主集准备可继续，EGL 正式模型评测在此门禁通过前关闭。
