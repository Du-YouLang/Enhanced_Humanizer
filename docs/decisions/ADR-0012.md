# ADR-0012：P6 冻结基准、独立环境和诚实的未运行状态

2026-10-11 用户授权继续 P6，并提到 P7。两份保留的 v0.4 合同只定义 P0–P6；P7 尚待用户确定范围，不能自行增加发布承诺。P4/P5 本地功能已通过，远程 GitHub 操作仍按用户要求暂缓。

P6 保留 6 BugsInPy、6 SWE-bench Lite、4 科研任务和完整 A–F、J0–J3、Merge 消融。先冻结公开实例的身份和原始材料哈希，科学任务保留确切题目及缺料状态。12 个公共实例按元数据/准备成本选取，无模型结果参与选择；这是一组便利样本，不代表全部基准分布。四项材料空缺的槽位不等于四项已完成的科学任务定义。

使用项目内 Miniforge 26.7.2-0，同一任务的各臂共享相同的固定 Conda 环境、初始 SHA、权限和硬件。历史 Black 任务使用原定 Python 3.8.3，Harness 的 native Python 3.12.3 保持原样。准备时间单列。下载/安装/尝试日志及依赖原文留在私有目录，环境封条包含文件内容清单、Conda explicit、pip freeze 和 Python 版本，模型不得修改环境。安装发生在非 root 账户，不改 Windows 系统环境。

隐藏验收使用现有 Humanize Fence 和非 root 私有 PID namespace，复制独立候选源码后只读执行，运行临时文件单独允许写入。参考实现、Codex auth、控制器状态不可读；环境文件不可写；实际进程先运行权限探针。内部相对符号链接（包括未生成文档的悬空链接）保留，越界/绝对链接拒绝。Python 3.8 的 http.server 导入需要 `/etc/mime.types`，仅允许该公共文件只读并记录 SHA，不放开整个系统目录。原始测试输出保留在私有证据里，不交给 Reviewer/Judge。

每项任务只有错误基线失败、官方参考修复通过且测试确实收集/执行后，环境验收器才算有效。导入失败/零收集不能被误报为能力失败或 PASS。Requests 旧测试涉及 HTTPBIN 服务；在固定服务与权限尚未验证前，其环境不进入模型对照。当前实现的本机验收接口不等于官方 SWE-bench Docker leaderboard 成绩，必须说明环境偏差并单独验证全部 FAIL_TO_PASS/PASS_TO_PASS。

P6 真实 smoke 预算另行询问：USD5、200 DS 请求、32 Codex 订阅回合，120秒/请求、600秒/角色或候选、1200秒/实验；截至本交付仍未批准，P6 Ledger 与模型入口未开放，不结转 P5 余额。源码开发和环境准备不调用模型 API，主实施 Agent 的订阅 Token/费用不可见时写 unavailable。

初始 manifest v1 保留为历史准备版本。v2 仅修正对既有模型身份的表述：此前 P1/P2 文档描述 V4.1 Flash，P6 固定已验证的 deepseek-flash/gpt-6.1-sol 请求身份，每次真实运行保留返回模型信息，不能从 alias 自行推断或切换版本。任务、seed=42、一次探索性重复、N=3 及两项 smoke 身份不变。任何后续更改建立新 manifest 和决定记录，不覆写已冻结版本。

报告校验 task/arm/seed、源码、环境、硬件、权限、隐藏验收、运行证据及模型/Harness 身份。MOCK、改 seed、改环境、Judge 高分不能成为 PASS。API 实付、保守上界和订阅额度分列；缺值保持 unavailable。保留所有已运行失败，未运行单列覆盖度，不画成 0 分。Wilson 区间仅作探索性描述，便利样本/臂间相关性使它不能支持总体显著性推断。
