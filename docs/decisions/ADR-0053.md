# ADR-0053：STROKE验收输入读取修复与已完成数值阶段复用

九项补验收原cf4f批次完成三项EGL、54次训练及独立权重复验后，在STROKE-A的重复检查之后停止。原因是验收器把含Unicode通道名/JSON元数据的可信输入NPZ交给仅允许数值/布尔数组的候选输出读取器。这是基础设施错误，不记为模型失败；原日志、started标记及完成产物均保留。

可信输入改走独立`owner_npz`：先核对原冻结字节SHA，再用`allow_pickle=False`读取。候选输出的原大小/shape/dtype/数值边界完全保留。新正负检查覆盖合法Unicode输入、指纹不符拒绝、pickle对象拒绝，以及原输出读取器仍拒绝字符串。

恢复根7314ee583300、planea51357d绑定原三份完成阶段和STROKE-A已完成重复执行的精确worker、原候选树、输入、profile、执行回执及保存结果；21数组和JSON重新只读比较通过。三个EGL完成阶段逐字复用，不重训；STROKE-A重复不重跑，仅继续尚未执行的拒绝检查与图表准备，随后其余五格。原候选和裁判不改，模型调用0。428保留pins加10源码pins，旧账本完整SHA同样固定；原三格442.877秒及中断阶段30秒保守计入总限额，STROKE-A只剩570秒。

新源码/实际隔离控制、原生及Windows测试、精确CI和实际启动均须另有回执。首90e749准备根保留，最终7314另加运行时重复身份与非负耗时门。未确定started不自动重放，所有原结果继续保留。用户原USD500/10000及Luna只读/Sol科学代码分工不变，产品PR人审和对外发布确认保留。
