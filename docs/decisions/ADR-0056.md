# ADR-0056：关机后接回指导会话并续行剩余任务

用户在2026-10-16要求关机，原恢复批次按精确拥有者正常SIGINT退出，保留11题、56个完成角色、33份冻结候选和四题12份质量补验收。用户随后明确要求继续；累计15000DS请求/USD500及所有未知预留不变。

Sympy11870的DS首轮已经正常完成；轨迹导师只留下started、实际隔离回执及官方Codex线程和工具轨迹，缺少完成回执。旧线程117322输入/76928缓存输入/1029输出Token记录保留，不能视为零消耗。恢复先验证原始会话、代码、输入、账本前缀和全部56完成程序，复制独立会话存储后通过Humanize原有Codex thread/resume接回同一线程；不从头运行导师。唯一适配点为上游现有session adoption方法，模型、low强度、工具、schema与实际只读OS隔离均继续由原Harness处理。

原角色已耗时间按started至正常退出向上取整保守计入，43秒扣除后最多857秒，不能获得新的900秒。新订阅回合累加到原作用域；旧未知预留不退款，原117322等计量与恢复增量分开，若计数基准无法确认则明确unavailable，不双计复制的日志或编造Token。原中断会话、日志、started和停机回执不可改写。

独立副本的Codex线程索引仍记录旧虚拟HOME的绝对rollout路径；只在确认副本恰含原线程后，将这一条索引重定位到字节相同的副本JSONL。线程ID、历史、原数据库与原日志不变。原生实际只读隔离下官方thread/resume零推理控制已证明可接回原线程；首次canary不存在、重复隔离回执及旧索引路径的控制失败均留档，未调用模型或变动账本。正式付费仍以最终源码控制/CI为准。

导师真实完成后才追加原阶段完成记录，复用原题DS首轮；仅运行另一个未开始导师与两个DS续改，再推进四项从未开始科学任务。11题、56角色、12补验收一律复用，不整题或整批重放。新的单次启动标记、作用域限制、冻结计划、实际官方thread/resume零推理控制、真实只读隔离、完整公开正负控制和精确CI均为付费启动前提。

两个DS分支冻结后才进行隐藏验收。关机恢复的活动时间与离线停机时间分开，四项旧基础设施影响仍标注；数值通过仍需Sol独立源码、方法、报告和图表审核。Luna只读监控、Sol负责科学和代码。旧付费开机恢复入口保持禁用，新批次启动后再接回只读监控与本会话45分钟跟进；产品逐PR人审和对外发布确认不变。
