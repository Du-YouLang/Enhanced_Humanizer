# ADR-0001：保留 v0.4 基线并处理旧版引用

状态：accepted（按用户本轮明确指定的 v0.4 基线执行；非新增需求批准）。

依据：用户要求完整阅读两份 v0.4 文件、仅执行 P0、保持需求完整。

发现：PRD 开头仍指向 Implementation Guide v0.3，§16 仍要求比较旧指南；本目录只有用户提供的两份 v0.4 文件，未发现 v0.2/v0.3 或原始讨论记录。不能声称已完成历史逐行差异扫描。

决定：本轮以实际提供的 Implementation Guide v0.4 + PRD v0.4 执行，保留两份原文件的精确字节与 SHA256；不回写 PRD 的遗留引用。其 Δ-01–07、S0–S4 和附录 A–C 均保留。后续若取得历史文件再补差异审计，不阻塞 P0。

追踪：80 项主需求 + O-01–06，见 `docs/requirements/traceability.json`。用户新增暂定名称提醒以 USR-NAME-01 单独记录。表格里的验收编号是计划，绝非通过记录。

补充目录解释：指南正文要求 `docs/requirements/traceability.md`，目录树示例写作 `docs/traceability.md`。以正文路径为主，示例路径提供索引，避免重复维护。

影响：不删减任何已确认要求；缺少旧版原文属于审计限制。当前 P0 Gate 保持未通过。
