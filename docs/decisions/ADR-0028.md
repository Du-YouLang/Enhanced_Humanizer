# ADR-0028：本机重启恢复与不重复执行

2026-10-12 用户明确授权补充关机／断电后的续跑、开机自动恢复，已完成任务不得重跑，预算和日志继续累计，并不得干扰活动 benchmark。这项授权允许本批次重启后自动启动尚未开始的任务／阶段，不修改 v12-final2 的模型、角色时限、数值门、凭据边界或累计 10000 次／USD100 上限。

实现独立 Windows supervisor 和只读 WSL inventory；冻结入口、主集 runtime、manifest 和原批次索引不修改。当前控制器存活时仅观察；控制器丢失而 native controller 存活时接管观察，不另开模型。仅检测到 Windows 新 boot 后才调度本批次尚未启动的 execute/sensitivity 槽位。

已完成整题包括含 FAIL/TIMEOUT 分支的 `MAIN_TASK_COMPLETED`，均跳过；完整 sensitivity 回执绑定原 execute run。缺回执、半写 launch、未完成模型角色不当作未开始，也不自动重放整题。这些中断保留为 pending，继续其它未开始题；依赖未完成 execute 的 sensitivity 保留待完成源。此实现是任务／阶段边界恢复，不是任意 token、未提交 patch 或训练 minibatch 的原位恢复，不宣称中断题已完成。现有 Humanize checkpoint 不能自动证明主集任意阶段可恢复。

每个新启动先 fsync hash-chain journal 和原子 intent，之后才允许冻结入口读取凭据。崩溃发生在启动与回执之间时 inventory 核对 native launch/contract，不能确认的 intent 保留且不重复执行。OS 文件锁限制同一 supervisor 只能一个；Windows PID、创建时间、命令及 executable 核对，native start ticks 仅在相同 boot ID 下可信。存在未知 controller 时拒绝新增启动。

账本只读检查累计前缀身份、顺序、授权和总和，不退款未知 usage，不修改历史预留；恢复的新任务继续使用原 MainLedger。新启动日志 append 保留，损坏/残缺 journal 尾部失败关闭并保留原字节。普通角色失败仍属模型结果，断电不凭空转换为网络失败。

当前用户登录后启动，因为该用户拥有 WSL distro 与项目凭据；不配置自动登录、不使用 SYSTEM、不存密码。优先用户 Task Scheduler，非提权 token 无权限时使用单独 HKCU Run 值；所有实际程序/config/log 保留项目 D 盘。退出 Codex 不影响该启动机制。关闭 enabled marker 可停恢复观察而不终止活动 benchmark。安装、模拟进程崩溃、重复启动/账本控制与活动批次零影响证据独立记录；未经实际断电验收不声称物理断电测试通过。
