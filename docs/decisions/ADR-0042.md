# ADR-0042：多次基础设施暂停后的保留链与90格续行

日期：2026-10-15。

实际状态已暂停，历史启动说明不代表现在仍在运行。第一批13格加第二批9格合计22/112：17 PASS、3 FAIL、1 INFRA_FAIL、1 INFRA_RETRY_PENDING。最新Black-4/P1/订阅在100.797秒、12次SDK dispatch后报Subscription Sharing usage暂不可用；原结果、会话、候选与账本不改写。监控多次健康核对不能代替恢复工作。

本次核验官方[错误恢复文档](https://developers.openai.com/siwc/token-sharing-open-source/errors-and-recovery)：`subscription_sharing_usage_unavailable`对应503，可用量检查暂不可用，保留凭据并有限退避；这不是`usage_limit_exceeded`，也没有证据是认证/配额失败。原轨迹只记录消息没有HTTP/code，因此该文档匹配是诊断支持，不能虚构原HTTP实测或把它改叫过载。当前SDK OAuth令牌自然过期，已通过其官方refresh实现串行刷新并保存原单文件私有备份；GET官方模型目录实际200、gpt-6.1-sol列出。零模型调用且账本逐字不变，目录访问通过不保证推理服务已恢复。该流程参照[官方模型目录](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)，不走ChatGPT内部接口，不切换账号/模型/计费。

用户原完整补测范围仍有效，本次只推进90个从未开始格。单独冻结v2计划6069a7a32fed58eb47cf7a1034c011c160a5d5a7584adb7f95cdcec6fb7593ca；将两批原始回执按顺序串联为不可重复的22格严格前缀，对剩余90格逐一检查所有旧目录都不存在，损坏、缺格、重复或不确定启动一律拒绝。包装器新版本仍调用原controller-add321ab的冻结run_cell、官方Pi SDK、fence和裁判，不覆盖旧包装器或原计划。

既有两项基础设施异常不包含在本次90格清单，不整格重跑，暂留后续独立处理。原22格和旧主集/敏感性/Pi16/所有历史预算行分别保留；累计10000 DS请求且USD200、角色900/1200秒、单次600秒、输出256000不变。起点6609DS/208订阅/USD114.6357972保守上界，实付不可见。

状态/观察器在新版本中按原22格+本次90格显示累计112；Luna负责只读，Sol负责实现和科学复核。科研数值通过仍需源码/报告/图表核验；P7精确包/外部发布尚未完成。自动化目标应随实际新拥有者回执更新，不能根据旧launch继续宣称活跃，也不能在heartbeat中无限重试模型。
