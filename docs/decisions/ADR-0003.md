# ADR-0003：仓库授权、费用与隔离门禁

状态：proposed；已明确的用户安全约束直接遵守，具体仓库与运行授权尚未获得。

关联：GC-01–07、SG-01–04、HR-02/03/07、OP-01、O-01–04。

本地 Git 已建立，主分支只有一个最小根提交，P0 工作在独立 feature 分支。远程仓库、Issues、PR、分支保护、Fork、付费模型调用和 main 合并均未执行；不把这些标记为通过。

拟用 `Du-YouLang/Enhanced_Humanizer` 私有个人仓库，创建后仅推送已扫描的规范/代码/脱敏摘要。计划主干 PR + 必需 CI + 人类手动确认，关闭自动合并、force-push 与分支删除；账户套餐限制时明确采用 CI + 人工门禁。独立审批者不存在时不能要求同一账号自批 PR；不擅自添加协作者或提高权限。

现有 gh 身份已通过在线 user API 验证；全局 Git 作者名不同，因此本项目单独采用已验证账号的 GitHub noreply 邮箱，未改全局 Git 配置。既有 Git 凭据助手指向 Anaconda 安装，需在授权推送时实测，不能把公开 `ls-remote` 当作私有仓库写权限验证。

初始新增推理费用授权为 0。预算文件是待批准的提案，不能视为自动授权。只读 `/models`、CLI 状态、官方 fake driver 和 SDK initialize/close 均不发起模型生成。当前聊天 Token/费用不可见时记为 unavailable，不推算现金。

Windows 上尚无验证过的 Humanize OS 隔离。官方说明使用 Linux Landlock / macOS Seatbelt；DSH driver 仅提供 bypass rung，需外部 fence，见 [Humanize Security](https://docs.humanfia.ai/humanize/user/security)。独立 worktree 不能阻止跨目录读取或获取 GitHub 凭据；Prompt、Git hooks、UI 都不是安全沙盒。未通过拒绝访问测试前，不放行拥有工具写入能力的自主 Flow。

P0 的本地 push hook 在没有人工授权记录时拒绝推送，拒绝 ref 删除、未知目标与未批准 main SHA；本地治理单测覆盖这些拒绝路径。它可被本机账户绕过，不提供 OS 层防护。远程主干保护是否生效仍须真实验证。

P0 fake 预算探针发现成本限制在下一轮前检查；第一次调用可能先超过金额。正式调用前必须为请求预留最大费用、限制输出、重试次数与超时，不能把 Humanize 的事后统计当作严格硬上限。

缓存偏差及纠正：首次 SDK 初始化将两个原生扩展缓存写至用户默认 `.cache/pkg`。按创建时间及精确目录名确认归属后，已移动到项目 `.local-workbench/cache/pkg`；增加 `PKG_NATIVE_CACHE_PATH` 并复测，用户目录旧缓存路径已不存在。操作证据留在本地 ignored 审计目录。
