# ADR-0022：经用户操作切换 WSL 独立订阅账号

2026-10-12，主集 v8 的第一个完整尝试在独立 Sol Judge 阶段遇到原生 `usageLimitExceeded`。已有 TUN 和真实隔离下的 HTTPS 连接正常，错误属于旧 WSL Plus 登录的额度限制。批次停止；原角色、两个原生会话、未知 Tokens、7 个订阅预留及 357 次 DeepSeek 请求全部保留，累计 API 保守上界 USD4.2235404。没有把基础设施中止当作成功、退款或零使用。

用户明确授权改用当前 Codex 桌面账号，并亲自在官方链接完成 WSL 独立登录。第一次登录仍匹配旧账号，因此不启动模型；用户随后在无痕窗口完成第二次登录，核对原生认证元数据与桌面账号一致。认证内容和官方登录链接仅保存于项目私有路径；仅备份项目 WSL 的单个认证文件，不复制全局认证目录。账号标识、邮箱、Tokens、OAuth 链接不进入公开文档。

新账号与旧账号不同，属于显式授权的执行环境变化，不能隐藏。模型仍请求原 `gpt-6.1-sol`，每次运行记录实际返回身份和 usage；不依据计划名称或额度余量推断模型调用成功，也不消费重置权益或购买额度。

在确认登录后，由本次继续工作的授权启动新的有限 v8 批次。旧失败批次和报告保持不变，新批次单独索引；主集账本继续累计，不重置、不挪用已关闭 smoke 余额，不择优覆盖旧结果。原模型/角色/实验时限、10000 API 请求及 USD100 费用门禁保持。基础设施失败仍停止，没有自动重试服务。

本次切换不证明主集或 P6 已验收。完整矩阵、共同候选池评分、工具轨迹敏感性、科学来源/报告审核和延迟测量覆盖仍需按实际证据核验。
