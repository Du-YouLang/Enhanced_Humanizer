# ADR-0037 — 科研验收器修复与独立补充验收

日期：2026-10-14。状态：本地修复与补充验收完成；完整P6科学有效性仍有保留。

用户明确授权修复EGL、PC-ALM验收器和契约，再处理Pi同步缺陷；保留原结果，补充验收另存，不整题重跑，沿用USD200/10000请求上限，GitHub继续暂缓。本次计划零模型。

EGL正常CLI的SystemExit(0)/None必须执行可信收尾；非零退出、异常及不足5400次训练接口调用仍失败。统计/内存字段仅接受明确的等价schema与单位转换，重算每组和配对统计，不因字段名不同拒绝正确数据，也不隐藏冲突。旧七份缺失使用计量不能事后填成5400：复用已有曲线/50个探针，仅对数值门通过的候选补缺失的独立保存权重验收及源码/图表审阅。D补充PASS，数值通过但缺少运行期计量的DS0/A/C/E保留INDETERMINATE；B/M/F真实数值FAIL保留，不重训补分。

PC沙箱有意移除.git；完整程序身份由可信父进程的源码快照摘要绑定，不要求被隔离的子进程读取Git，且不把上游commit冒充候选commit。候选实测Python/包版本、数据hash、逐Gate耗时经明确语义映射；缺失驱动信息仍为unavailable，不用当前驱动填造旧测量。官方源码指纹、75格/原生记录、锚点与本机冻结0.25pp/0.02容差不变；仅对这些门已通过的原候选补原本缺失、由完整程序身份确定的两格独立验收。完成格与完整网格不重放。

Pi修复只在独立副本的既定一处ridge写入后加入CTA屏障，原候选/原数值成绩/原源码FAIL不覆盖。新副本冻结后编译PTX确认屏障，并用小规模独立CPU参考和有限重复验收；不重跑Pi矩阵或冒充模型自行修复。所有新增计算记录耗时、隔离和输入/输出摘要。

补充裁决独立绑定原回执、冻结源码、原产物及新检查器；原96格、Pi16格、选择和累计账本不变。旧P6报告保持，新补充说明不得混算修复后新候选与原成绩。此前45分钟轮询已在所有原运行结束后删除，本机30秒只读观察器保留；本轮验收控制器由当前会话直接核验。

实际PC七份候选通过既有75格/锚点/数据/源码绑定、14次缺失单格验收与编排/75格报告审阅；F余弦偏差仍FAIL。Pi新手工副本a7ac0bf2的PTX在原store/load之间新增bar.sync；23个独立小输入与8次重复全部通过，最大绝对差6.3144e-16。原源码9be645e2及其FAIL、原成绩不变，没有运行sanitizer或完整矩阵。所有新实验API0、原累计账本b54271dd不变。
