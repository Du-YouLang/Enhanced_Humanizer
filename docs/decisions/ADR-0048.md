# ADR-0048：EGL逐种子配对汇总的明确字段别名

2026-10-16，Pi EGL/P0/DeepSeek完整训练正常结束，已有5400次训练阶段EG调用及独立保存权重复验。原FAIL发生在summary_and_manifest：paired_differences使用values/mean/std记录完整的三种子差值、均值和样本标准差，旧验收器只读取更长的字段名，产生KeyError。公开契约已允许等价的完整配对统计，因此不能将此直接归因为数值或训练失败。

独立源码在groups形式的paired_differences中支持两组穷举别名：per_seed_eg_minus_gd_pp与values、mean_eg_minus_gd_pp与mean、std_eg_minus_gd_pp与std。多个声明必须一致；所有声明均检查类型、有限性和三种子覆盖。缺失值、布尔值冒充数值、冲突、种子错序和总体标准差仍拒绝。均值、逐种子次序、ddof=1仍由原18份原生metrics重新计算验证，不填补缺失测量，不放宽任何数值阈值。

修复仅进入独立开发源码，不修改运行中的内容寻址副本、候选、summary或原FAIL。补充检查使用原执行回执和已有权重复验；入口禁止任何新的候选或数值执行，重新检查原18组曲线、参数、训练使用记录、CSV、manifest与统计。实际补充结果PASS_NUMERIC_REVIEW_PENDING，模型0、候选执行0、数值重放0；源码/报告/图表审核前不计完整科研PASS。

EGL/P1及P2/DeepSeek另有保存曲线超出原冻结1pp阈值，不能因P0的字段修订而一并通过。逐点核验显示差异发生在训练过程多个采样点，尽管末次准确率一致；源代码与浮点运算路径的进一步归因另记，不将“阈值超出”等同于已证明算法错误，也不追改原阈值或重跑整题。
