# ADR-0010：P4 工程记忆与无损恢复

2026-10-10；用户明确授权 P4→P5，并授权本轮按需预算。P4 不需要新模型调用，API 现金和订阅回合新增均为 0；历史开销保留原阶段归属，不重复相加。

采用项目本地 append-only NDJSON 作为事件权威，SQLite 为可重建查询投影，SHA256 内容寻址 artifacts 保存完整日志、代码、测试和配置。事件有序号、前向哈希和 fsync；断电后完整事件重放，残缺尾部拒绝启动并保留原件。哈希是损坏检测，不声称能抵挡有权限同时重写全库的本机管理员。

事实、假说、被否定、已取代和未解决是显式状态；更新追加事件。结构化交接携带节点对应合同、恢复 SHA、证据与失败历史，不传播原始对话、隐藏测试答案和人类专属完整 trace。相同内容遇到不同访问级别保留更严格级别。私有数据目录不进入 Git，公开报告仅使用既有受控合成任务。

历史 fork 创建新的 Git worktree/分支；脏工作区先在新 worktree 程序快照，清楚标明非模型成功；revert 也创建新分支，冲突保留。Windows 控制器不执行候选代码，测试交给既有非 root Linux namespace/fence。备份包含事件、artifacts 和所有 Git 分支的 bundle，恢复至新目录校验 manifest 后重建 SQLite；不含凭据、WSL OS、Python 环境，原版 runtime lock/WSL 安装流程另行管理。

每次产品 PR 需要独立、限时、绑定精确 head/证据/目标的人工能力凭据，并原子地单次消费；模型声明 actor=human 不构成批准。开发 PR 的 CI 合并政策不授权产品 PR。P4 的批准测试仅使用明确的测试能力凭据，不冒充用户审批。

P4-A01..A04：真实 P3 历史逐节点恢复、失败硬测试复现、交接、备份新目录恢复和对抗测试；功能通过后还需开发 PR 的实际 CI/main 同步才完成交付。P5 执行界面和 P6 科研对照分别验收，不能从历史机制推断增强有效。
