# ADR-0015：P7 本地源码预览包与安装边界

用户于 2026-10-11 定义 P7 为安装打包和交付准备，并要求发布前确认、GitHub 暂缓。保留 P0–P6 合同；P7 是新增用户范围，不将原阶段失败或缺料改写为通过。

采用干净 Git commit → 公开源码 ZIP + 单个 HEAD 可达历史 bundle + 精确逐文件 SHA 清单。交付只生成于 `.local-workbench/deliveries`。安装需要独立 ZIP SHA，全部成员先验证，拒绝越界/绝对路径/Windows 特殊设备名/大小写冲突/链接/重复/多余成员/大于250 MiB；目标须为当前项目私有目录下的新目录。安装后检出精确 commit、禁用新仓库 hooks、比对全部 Git blob，保留失败目录。

包不重新分发 Humanize/DSH/Codex 可执行文件、Python/Conda/WSL 或任何账号/原始实验状态。Windows venv/cache/tmp 留在安装路径，hash 固定的 PyYAML 为单独本地依赖。`doctor` 检查可见前置条件，零模型/零远程 Git；认证文件仅检查存在布尔值。源码没有用户选定的许可证，保持待定，不为外部发行自行授予许可。

预览安装与现有科研运行状态分开：新 UI 可用，推理入口默认拒绝，不能拿打包的历史预算配置自动批准新主机开销。新主机完整运行依原 P0 验收，不承诺即插即用。启动器优先用安装 venv，按健康接口项目路径核对端口归属；后台隐藏窗口，不停止他人的服务。

源码包与 P4 工程记忆私有备份各自恢复到新路径。回滚选择旧 commit/旧包和独立端口，不删除 WSL/VHD 或旧安装。完整 P6、远程 CI/交付、真实产品 PR 审核和最终发布仍独立验收。
