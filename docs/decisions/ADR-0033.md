# ADR-0033：Black-5 单分支检查点续跑与后续本地交付

2026-10-14，用户明确授权先恢复 Black-5 中断的 Pool-A，保留已完成结果，不整题重跑；随后推进 Pi 正式任务对照和新版 P7 打包。沿用累计 USD200 / 10000 次 DeepSeek 请求上限，GitHub继续暂缓，产品逐次 PR 人审和对外发布确认不变。

原运行 `p6-main-execute-BIP-black-5-20261012T151835Z`、失败记录、公开候选池及 DS0/B/C 原始文件全部保留。原 Pool-A 已预留63次请求，控制器角色耗时370.99639050599944秒；续跑仍用原 Pool-A 请求 scope，剩余529秒和937次请求。按原启动回执至失败文件时间的向上取整，保守扣除1029秒活动预算，后续最多6171秒；该扣除值不是准确模型耗时，丢失的原墙钟区间记 unavailable。

原 Humanize Flow 标记不可恢复；已安装的官方 DSH SDK/CLI 没有经验证可跨进程恢复该会话的接口。因此采用**同一文件检查点的新 Humanize/DSH 会话**，不声称原生会话恢复，不更换 Harness 或模型。复制其自身历史轨迹和工作区，保持完整轨迹审计。DS0/B/C仅复制并核对程序与公开证据，不调用模型。新的公开池仅替换恢复后的 A；选择先冻结，再运行隐藏验收。

续跑控制器部署到独立 recovery 目录，冻结59份原生源码不覆盖。当前原生预算模块已是先前批准的 USD200 版本，其他原始57份共同源码不变。主目录同步已有现金上限模块和配置以供本地测试；不触发远程CI。新续跑清单单独冻结，零模型检查点/隔离控制和预算测试通过后才允许调用。阶段开始与完成回执分别落盘；已完成阶段可复用，已开始但无完成回执的阶段必须核验，禁止自动重复计费。

Pi沿用已准备的两个任务、四种 profile、两个 provider 的16项正式对照，先完成真实工具和各profile资源/隔离门禁；旧256项方案不自动启用。DeepSeek与Pi订阅调用均写入原累计账本；独立登录的官方ChatGPT订阅不冒充OpenAI API。P7仅本地安装包、独立安装与回滚验证；不把打包或准备阶段当作P6/Pi验收。

实际进度以补充审计、私有启动/阶段/最终回执为准；本决定不预写任何模型成功结果。
