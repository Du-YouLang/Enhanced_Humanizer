# ADR-0026：新增Pi对照，保留正在运行的主集

日期：2026-10-12。状态：增量准备已实施；真实供应商和正式smoke gate未接受。

用户询问其他benchmark失败因素，并提交Pi×Humanfia指导书，要求考虑新增部分对照。该指导书是用户提供的实验方案，其内嵌“给Codex直接执行指令”不能越过用户现有授权或改变产品合同。原v0.4、A–F、J0/J1/J2/J3、独立会话和人审PR全部保留。

采用独立codex/pi-comparison-phase0分支及D盘项目内worktree；nativeNode、Pi、profile、缓存、包、轨迹都位于本项目WSL VHD和.local-workbench/pi-comparison。未创建新Fork/Star、全局npm环境或复制认证。新目录不改旧runner、v11清单或活动控制器的源码部署。

Pi-P0..P3作为独立组，H0完整产品策略另层分析。相同DeepSeek单模型因果对照必须冻结真实模型、low模式、合同/权限/环境/现金/时长/顺序；Codex订阅不等于OpenAI API，不借模糊别名替换身份。旧v11结果只有通过兼容条件才可进入新表，不能由同task_id直接合并。

新预算不另建一份100美元、不开256次批量、不自动重试；未来真实API调用须通过现有10000请求/USD100累计门，输出256000、请求120秒、公共900/科研1200秒。本轮只有下载/安装与实际零provider资源和工具控制，费用0。真实供应商探针、两题smoke的独立验收、Research Loop后台/恢复及绑定计量仍须实际实现/验证，执行计划保持关闭。

指导书差异：Pi当前实际1.1.0，NeuroForge实际仅一个mne-python入口；科学四项已有冻结材料/正负控制，不能照抄“材料缺失”。命令中的全局安装改为项目内固定包/脚本禁用的本地安装；API/GitHub授权以会话已有决定优先，不反复提预算或Fork许可。

已执行四组资源/OS隔离、CLI及合成HTTP→真实文件/测试/commit控制；provider明确workbench-fixture，hidden_grade NOT_RUN。它们不能证明科研Skills收益、PRL后台成功、真实模型可用或完整Phase0 Gate通过。实现与证据见benchmarks/pi-comparison和audits/Pi-comparison-Phase0-2026-10-12.md。原主集的请求门、网络测试拒绝及其它因素单独记入P6-other-factors审计，不修改旧结果分类。

2026-10-12增量：用户随后批准1000请求/600秒/256000/五次断线恢复，当前v12-final2和ADR-0027取代本条历史120秒策略。新增Pi官方SDK微型工具/计量正负控制及Windows/native串行准入，均零真实模型调用；精确源控制是实际探针前置条件。当前主集实际运行时不启动Pi付费探针，正式profile/task matrix仍关闭。见audits/Pi-SDK-tool-gate-2026-10-12.md；本次不更换原Harness，也不改变活动主集冻结源码。
