# ADR-0049：STROKE补充审阅区分数值通过和输入契约缺陷

2026-10-16。Pi补测全部执行完成后，Sol逐份阅读STROKE八份冻结main.py与README，对照原任务的输入和数值协议。各候选原14项数值、1项精确重复、6项拒绝输入检查全部通过。管理员仅从保存数组生成六种公开输入/profile图，共48幅，不执行候选main；6幅实际查看，42幅与已查看图的SHA逐字节相同。图像只支持展示审阅，数值判断仍来自独立原协议检查。

源码检查发现DeepSeek P0/P1/P3将artifact_reviewed/synthetic用bool转换；JSON字符串false会变成True，P3还对缺失artifact_reviewed默认True。原TASK第40行要求未审查输入必须显式允许、无效输入非零退出，第48行要求保留原输入布尔值。这是原契约的源码缺陷，不是新增数值容差，也不能因为原六类拒绝测试未覆盖它而忽略。此结论来自完整源码路径，不虚报新反例执行。其余五份显式验证原布尔字段。

因此八份保留数值与图表正面证据，完整补充审阅单列5 PASS（订阅P0–P3、DeepSeek P2）及3 FAIL_SOURCE_INPUT_CONTRACT（DeepSeek P0/P1/P3）。最早八份数学/图表范围PASS回执保留；后续v2判定明确纠正将这些范围PASS扩大成完整成功的风险。原八项INDETERMINATE、模型输出、原矩阵、私有参考和预算均不改，不替模型修复输入处理。对输入完整性之外的生产健壮性不作穷尽保证。

所有者批准的是冻结传感器协议的一致性评测，不是患者组论文复现、临床有效性或PCI有效性。真实健康子集仍未完成伪迹审查，200次bootstrap也不证明尾部估计稳定；这些限制必须进入最终P6报告。
