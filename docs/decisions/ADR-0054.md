# ADR-0054：DS 首轮、Sol 指导、DS 续改的配对验证

用户在2026-10-16明确要求完整16题验证，并批准累计15000次DeepSeek请求、累计USD500。原9267请求/256订阅/USD234.7862361保守上界、166次未知用量预留和全部旧结果保留，不充值，不替换旧成绩。首轮至续改的增益同时含新增DS处理时间，不能单独归因于Sol；两组续改的配对差异用于观察额外轨迹的作用。

每题一个全新DS首轮检查点。两组独立只读Sol导师分别获得代码与公开测试，或额外获得完整可观察工具调用和结果；不提供私有推理、凭据或隐藏答案。Sol只提供结构化文字指导，不改代码。两组DS独立新会话从相同完整代码检查点续改。首轮、导师、续改均low，公开角色900秒、科研1200秒；DS每角色1000请求，单请求600秒/256000输出，瞬时传输最多10次尝试含首次，逐次记账。既有2小时/3小时模型活动保护不变。

全16题各有首轮与两组续改结果。导师与续改先按题号奇偶交替次序运行，避免总是一组先运行；不按结果选择顺序。两组最终程序全部冻结后才对首轮与续改执行隐藏验收。导师代码只读权限由实际OS隔离控制核验，另一组输入/状态不可见。上下文完整提供或明确拒绝，不静默截断。新的科学契约使用现已核验的PC/EGL修复、STROKE公开明确metadata契约和Pytest公开缓存修正；旧容差、原数据和隐藏补丁不变。

报告首轮通过数、修复/回退配对、各组16题通过数、时间及分供应商/缓存Token。共同首轮在实付总账仅计一次，方法投影分别含首轮且注明不可相加。科研数值通过仍需Sol逐份源码/方法/报告/图表审核。单种子小样本不足以证明普遍优胜，也不是等Token预算试验。完成数量不等于成功数量。

新内容寻址执行器和预算作用域隔离旧运行；同锁归档旧账本后只改请求上限与授权。完成子步骤按哈希复用，启动但无完成回执的步骤保留并阻塞，不能整题重放。实际本机零模型控制、测试、精确GitHub CI与真实启动/监控回执分别记录；准备不代表已经运行。Luna只读监控，Sol负责科学核验和代码。产品逐PR人审、名称/许可/对外发布关卡不变。
