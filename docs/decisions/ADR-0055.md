# ADR-0055：指导实验的冻结助手路径修复与不重放续行

2026-10-16巡检发现原指导批次的Requests1963/2148与Pytest11143三题九份候选公开验收都被拒绝执行。任务命令从历史JSON加载，仍指向原`/opt/workbench/source`，新隔离执行器却只允许对应冻结副本。首次部署只替换源码文本，未绑定序列化argv；原32项控制检查了隔离，但未真正运行软件任务的公开工具，因此漏掉了问题。不能把这些`INFRA_FAIL`公共门禁对应的原始`FAIL`标签解释为模型失败。Pytest11148亦受影响，合计四题。

原拥有者415已在没有未完成模型阶段的边界以普通SIGINT安全退出，保留STOPPED_PRESERVED回执和原文件。49个模型角色全部已完成；只中断了Pytest11148的轨迹分支公开验收，未中断模型推理。该题尚有一个从未开始的代码/测试指导DS续改角色；后面六题均未开始。

修复只对三种可信测试助手的完整argv路径做精确别名绑定，保留解释器、测试选择、断言、环境、隐藏补丁与容差。未知或嵌入式旧路径拒绝，不扩大文件或网络权限。原始冻结执行器不改。新增实际全部12个软件任务的公开gold、隐藏gold/buggy正负控制，以及真实编码OS隔离下公开工具控制。未映射测试身份不再报告为已执行数量；原计数留档。

恢复使用独立、内容寻址的新计划：复用原九个完整任务；复用第十题四个已完成模型角色和原指导，仅结束原条件下最后一个未开始角色；后续六题使用修复后助手绑定。严格付费作用域防止重放任何已完成角色。原公开验收中断只补非模型完成记录，原started标记、原数据和原台账保留；不明产物或已启动付费范围阻塞复核。原累计15000请求/USD500不变，所有旧记录与未知预留保留。

四个受影响任务仅用原冻结程序补公开与隐藏验收，结果另存为代码质量补充；原始矩阵不改。由于编码与指导时见过基础设施错误，它们不能自动并入严格同条件的指导效应比较。完成全部16题仍须区分程序质量、流程条件、独立科学源码/方法/报告/图表审核；不因此宣称普遍加速、省Token或因果优胜。

恢复正式启动前仍需实际本机控制、精确源码测试与GitHub CI回执。新拥有者、预算前缀与监控接管另取真实回执，准备不等于运行。Luna只读监控，Sol负责修复和科学核验；产品逐PR人审、外部发布与名称/许可关卡不变。
