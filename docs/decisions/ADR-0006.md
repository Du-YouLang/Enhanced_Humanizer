# ADR-0006：Linux 原生 Python 与执行边界

日期：2026-10-10。状态：采用，源自实际兼容性和拒绝测试；不修改两份 v0.4 基线。

Ubuntu 24.04.5 的 WSL2 kernel 6.18.40.1 支持 Landlock ABI 7。最初安装的 uv portable CPython 3.13.14 缺少 `os.pidfd_open`，Humanize 网络 fence 检查抛 AttributeError。该环境保留在 VHD 内 `/opt/workbench/.venv`，不能据此说 Linux kernel 不支持隔离。

Linux Humanize 改用固定 Ubuntu 镜像自带 CPython 3.12.3，独立环境 `/opt/workbench/.venv-linux`；满足 hmz 的 Python >=3.12 要求，原生 pidfd 和 seccomp 检查均通过。记录实际 Python 二进制 SHA-256；安装前校验，变化则停止重审。Linux 哈希锁包含 31 个包，Windows 32 个包中的 tzdata 是平台差异。Windows 原环境继续保留。

项目专用发行版使用无 sudo 的 workbench 身份。关闭 Windows 磁盘自动挂载和 Windows 互操作。工具、环境、缓存、模型状态、实验和证据位于 ext4 `/opt/workbench`，物理磁盘在已批准的 D 盘 VHD 中。Codex 使用新完成的 Linux ChatGPT 登录，没有复制 Windows 认证目录。

沿用 Humanize 自身 Landlock/seccomp/proxy fence，并显式收紧角色的 user/system/online 权限。候选版本采用无 hardlink/alternates 的独立 Git 对象库，避免普通 linked worktree 共享 `.git` 暴露其他候选内容；权威 main 和推送凭据在候选边界之外。P0 用合成 fixture 验证内部编辑/commit 可用，外部写入、相邻读取、凭据 canary、软链接逃逸、main refs、强推和外部删除被实际拒绝。

威胁边界必须准确：CLI 为登录运行必须读取自己的登录状态；该授权运行时的凭据不是被测试的“宿主凭据”。没有授权复制或读取宿主 key 内容。任意能写候选 Git 的进程仍可重写自己候选的私有历史，这不等于能更改权威 main。Git hooks 只是开发防误操作，不能替代 OS fence。P0 测试不是对敌意内核、所有 Unix socket 或所有侧信道的安全证明；后续候选并发必须继续验证独立会话/状态根，不能复用宽泛可写根。

验收证据：`docs/audits/P0-Linux-2026-10-10.md`。关联 WF-01、HR-01..HR-07、SG-01..SG-03、O-02。用户先前批准安装和路径方案；这是授权范围内的兼容性修复，不增加收费服务或系统盘例外。
