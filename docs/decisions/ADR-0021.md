# ADR-0021：主集连接前检与原生路由失败停止

2026-10-12，v5 首个任务的四个 DS 编码角色各实际运行约115秒并超时；随后 Codex 的原生 CLI 日志反复记录 workspace routing discovery timed out，没有生成助手响应。原协议将它们归为 TIMEOUT，继续了多个角色。人工调查后停止唯一拥有的主控制器，保留原始状态、源码、账本、日志和96项未完成报告；不把它们改成成功或退款。

零模型探测确认 Windows 现有代理可达 ChatGPT、WSL 直连超时。用户自行开启现有代理 TUN 后，WSL HTTPS 以及实际 Humanize fence/非root独立命名空间下均返回200；未修改 WSL 全局网络、主机允许清单或候选隔离。

v6 是独立冻结的新协议，保留16题/A–F/同池评分/轨迹敏感性、115秒角色/120秒请求/1200秒实验、100角色请求和已批准的10000请求/USD100总上限。每次模型任务启动前，用原 fence 做 robots.txt HTTPS探测，失败在读取凭据和调用模型之前停止。失败Codex角色仅在原生 responses_retry 诊断存在精确路由错误且没有生成助手/工具输出时标为 INFRA_FAIL，保留原始状态及原始证据hash，停止批次；普通TIMEOUT继续作为真实模型结果。诊断证据只能停止，不能证明成功。

首次v5运行和使用量不覆盖。新实验明确按新冻结版本执行，报告分别保留各协议尝试，不能从重试中挑选最好结果。科学数字通过与来源/报告/图审阅继续分开；主集未完成不能宣称P6验收。
