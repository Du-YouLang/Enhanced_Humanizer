# ADR-0027：新请求限额、连接恢复和 Pi 订阅

2026-10-12，用户明确要求每角色最多1000次请求、单请求最多600秒、充足输出及连续五次连接失败才提示检查，并要求全面审阅历史基础设施与当前代码。此指令取代旧100次/120秒及不自动请求重连规定；累计10000次/USD100、公共900秒/科研1200秒、整题7200/10800秒、模型身份、LOCAL_ONLY及数值门不变。

## 前瞻协议

另建预算v5和主集v12，不修改v11或更早配置/完成结果。v11有限批次已按Windows拥有者创建时间/命令及native PID-start-ticks停止。Requests-1963部分样本保留、排除验收；完成的Black-2与工具轨迹敏感性保留在v11。

预算修订在原账本锁内进行，先归档原始字节，完整保留1481DS请求、59订阅预留及USD25.0755186 API保守上界。未知用量仍保留完整峰价预留；连接失败可能已消耗服务端Token，不能记为免费。Pi访问探测另预留一个订阅回合，现金API费用0，订阅美元成本不可见。

## 连接恢复

DS固定官方端点的瞬态连接错误/超时及HTTP408/429/500/502/503/504重新连接，最多五次连续失败；前四次SHOULD_RETRY，第五次NETWORK_CHECK_REQUIRED。成功清零连续失败；后续独立请求重新计算。每个wire attempt均占角色与累计额度。若角色时间、授权余额或拥有者停止使重连无法完成，保留INFRA_RETRY_PENDING，不进入模型失败率。模型正常超时/输出限制/错误程序仍保留原分类。

完整流先由受信任传输缓冲，再送给原DSH；半截工具参数不会触发重复工具执行。缓冲上限显式32MiB；记录provider首delta与完整传输耗时。此改变会影响用户可见流式首Token时间，不能用于声称纯Harness时延改进。五次失败后熔断，DSH内层重试不产生新的上游请求。LAV使用同一计量恢复策略，并解除新协议下历史15次/$1的隐藏窄限额。

操作系统PermissionError、未知model、认证失败、坏usage/JSON不会通过重连绕开。尤其额外blackd服务器测试的socket权限拒绝，与模型服务连接错误不同。模型隔离、私有答案/账号/peer拒读、产品人审与数值判据不放宽。实际固定公开测试继续作为验收入口。

## Codex与Pi边界

现有Codex Harness保持官方app-server和独立订阅会话。连接前有最多五次真实隔离HTTPS探测；已有精确CLI路由失败证据保持基础设施分类。Codex内部请求/stream重试由CLI处理，当前外层只能准确计量实验回合，不能把订阅回合伪装成底层API请求，也不能把stream idle timeout伪装成600秒总请求期限。对DS的1000/600/五次wire控制已真实验证；Codex底层统一控制仍需独立实现与实测，报告明确标识该边界。

用户已亲自完成Pi官方ChatGPT OAuth，凭据仅在项目私有目录。Pi1.1.0动态登录采用加密身份元数据，不能与旧Codex明文字段直接比较；记录不可见，不能推断错账号。实际gpt-6.1-sol订阅访问通过，输入21/输出5Token、4.443秒、无工具。Pi返回的价目估计不是订阅现金账单；不使用另购API key、不复制全局认证。该访问探测不是编码/科研/四profiles收益验收。

## 验证与交付

真实installed DSH＋HTTP合成控制覆盖四次失败后恢复、连续五次失败熔断、半截工具流恢复，所有wire cap256000且已结算请求timeout600，零真实provider、实际主账本字节不变。重新验证角色时间/文件门/输出SDK控制，并绑定精确源码后冻结v12。单元/治理/秘密检查和GitHub CI依实际回执记录。P7旧包仅证明旧源码；新包需重新安装核验。产品Draft30继续待人工合并，对外发布未授权。
