# ADR-0013：P6 smoke 授权与 P7 本地交付范围

2026-10-11 用户明确批准此前 P6 smoke 提案，要求先推进公共任务、暂缓科研材料，并定义 P7 为安装打包和交付准备。GitHub 继续暂缓，对外发布前须再次确认。ADR-0012 和原预算提案保留为历史；不修改两份 v0.4 合同或旧阶段账本。

批准额度只覆盖冻结的 Black-2、Requests-1963 两项公共 smoke：USD5 / 200 DeepSeek 请求 / 32 Codex 订阅回合，120秒/请求、600秒/候选或角色、1200秒/实验，不充值、不结转。新建独立 P6 Ledger，调用前按请求、最坏现金预留和订阅回合执行门禁。失败请求保留未知预留，实际账单未知时不把保守上界当作实付。主集预算在 smoke 后按实际耗用估算，另行授权。

四项科学槽位由用户暂缓；仍为未运行，不减少 16 项合同总数，不补造论文、数据、容差或金标准。公共准备、smoke、主集和完整 P6 验收分别报告。Jev 的地区阻塞继续保留，Sol/J3 身份明确。

P7 在本地准备可校验的源码交付包、安装/启动/诊断说明、依赖固定信息、回滚和恢复步骤，并在新目录验证包内容及基础诊断。包不含凭据、私有运行历史、科研原始材料或 WSL 虚拟磁盘。实际 WSL 环境与账号登录不因源码打包而成为可移植安装；安装器须报告这些前置条件。不得自动重启、复制全局认证目录、卸载现有环境或对外发布。

首次外部产品发布前仍复核 Enhanced_Humanizer 名称、许可证与重用说明、模型访问、实际平台验收及人工 PR 审核。用户只批准交付准备；不能把本地安装包或模型 smoke 称为发布完成。
