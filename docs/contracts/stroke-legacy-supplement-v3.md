# STROKE原A–F补充验收契约 v3

本契约仅用于2026-10-16人类授权的原A–F六份冻结程序补验收。原卡片、原裁判、原结果、原程序均保留；不同于新Pi程序，不把本次结果静默写回原成绩，也不让模型或管理员修改候选。

数值计算、21类数组、全部dtype/shape、浮点误差带、显著性布尔及right-censor布尔均照原所有者裁判。NF有无、NF频率、其余标量/null、输入字节hash、样本/通道数、单位V、原布尔标记、PCI不可用和显式allow-unreviewed门均不豁免。

原公开卡要求“当前ROI顺序”但未固定JSON键名。`roi`、`roi_motor`、`roi_order`可以同义，均须逐项同序等于冻结输入ROI；同时出现的别名必须一致，冲突和错序拒绝。仅在可信父裁判内构造比较视图，原metrics文件不改写。

原卡明确无显著增强时NF=null，却未完整定义两个辅助标量。补充采用以下穷举表示规则：仅当参考和候选的`natural_frequency_motor_hz`都为null，`natural_frequency_motor_max_profile_db`可为null或原数值误差带内正确的有限profile最大值；全零无有限最大值时必须null。`natural_frequency_motor_at_grid_boundary`可为null或布尔false，不能为true、整数0或字符串。比较时将两侧这两个未定义辅助表示规范为null，并逐项记录原值；不把参考数字填入候选输出。不允许错误有限最大值、虚构NF、漏掉已检出NF或忽略任何核心数组差异。NF存在时两个辅助字段继续按原裁判严格比较。

输入metadata的artifact_reviewed、synthetic应为实际JSON布尔值；无效输入非零退出且不留成功metrics。除原六类拒绝外，补充字符串false/数值0/缺失标记等实际反例，分别报告原要求和补充覆盖；不将bool("false")视为合法审查。维持原14输入的保存数值证明，绑定原输入/输出hash；新增一次同环境重复及原六类拒绝，另做类型反例，不重做已完成全部数值主集。

新重复/拒绝使用公开所有者资源：一逻辑核、4GiB、每调用180秒、每候选补充600秒、PYTHONHASHSEED=0。原沙箱默认42保留；新显式参数只用于本次新执行，不追改历史计时/环境。所有候选仅在原文件/网络隔离内执行，无模型凭据。重复按JSON完整值和数组逐元素（NaN位置相同）比较，不比NPZ压缩字节。图由管理员从已验收数组统一生成，实际查看或精确图像hash复用均留痕，PNG不用于数值评分。
